# Uncharged Jewellery Reminder

Warns you when you enter the Wilderness carrying an uncharged amulet of
glory, ring of wealth, or combat bracelet — so you're not caught off guard
without a working teleport when you actually need to escape.

## Features

- Checks both your inventory and equipped items for:
  - Amulet of glory
  - Ring of wealth
  - Combat bracelet
- Shows an on-screen overlay with icons for any uncharged item(s) you're
  carrying — but only if you have no *charged* version to fall back on
- Each item type can be toggled on or off independently in the plugin
  settings, so you can ignore jewellery types you don't use

## Configuration

| Option | Description |
|---|---|
| Check amulet of glory | Warn about an uncharged amulet of glory |
| Check ring of wealth | Warn about an uncharged ring of wealth |
| Check combat bracelet | Warn about an uncharged combat bracelet |

## Why this plugin exists

It's easy to forget to recharge your teleport jewellery before heading into
the Wilderness — and finding out mid-fight that your glory has zero charges
left is not a great time. This plugin gives you a clear warning the moment you enter the wildy
